# macOS 配对与发送指南（纯 Python 模式）

在 macOS 上，本插件以**纯 Python 模式**运行土豆片核心：启动核心时插件会自动设置环境变量 `TODOOCARD_FORCE_PYTHON=1`，让核心改用 Python（bleak）实现蓝牙扫描与发送，**不使用 Swift 配对助手**。因此配对必须先在 macOS 系统层面完成（OS 级配对），之后才能在核心 Web UI 里扫描设备并发送。

## 配对与发送步骤

1. **先在系统里配对土豆片（OS 级配对）**：打开「系统设置 → 蓝牙」，确保蓝牙已开启。让土豆片进入可发现/配对状态（参见设备说明，通常是刚上电或长按按键时），在设备列表中找到土豆片（TodooCard / T3），点击「连接」完成配对。配对成功后设备会保留在蓝牙设备列表中。
2. **启动核心**：在思源右侧栏打开本插件控制台（「土豆片」图标），点击「启动」。插件会自动带上 `TODOOCARD_FORCE_PYTHON=1`，无需手动设置环境变量；纯 Python 模式不会调用 Swift 配对助手，也不需要在核心里执行任何配对命令。首次使用若弹出蓝牙授权请求，请点击允许。
3. **扫描并选中设备**：核心启动后，在控制台点击「打开传图界面」（即核心 Web UI，插件内页签「土豆片传图」，默认地址 `http://127.0.0.1:8199`）。在 Web UI 里点「扫描附近设备」（扫描设备），等待扫描完成（纯 Python 模式约 10 秒；界面提示的「约 30 秒」为上限），在结果中选中你的土豆片。扫描前请确保卡片处于唤醒/广播状态（刚上电或长按按键），否则扫不到。
4. **发送**：选中设备后，在 Web UI 里选择/生成卡片图片并点击发送。发送走 bleak 蓝牙连接，请让设备靠近 Mac 并保持唤醒。

## 排障：bleak 连接失败

如果扫描不到设备或发送时 bleak 连接失败，请依次确认：

- **设备已配对**：在「系统设置 → 蓝牙」里确认土豆片已配对/已连接。若配对失效，先「忽略此设备」，再重新配对一次。
- **蓝牙授权已允许**：在「系统设置 → 隐私与安全性 → 蓝牙」里，确认已允许对应的宿主应用（思源 SiYuan；若以 Terminal 模式启动核心，则还包括终端 Terminal / Python）。修改授权后需停止并重新启动核心再试。
- 设备电量充足、距离 Mac 较近，且未同时连接手机或其它主机。
- 仍失败时，可在控制台把「启动方式」在 direct / disclaim / Terminal 之间切换后重试；Terminal 模式下蓝牙授权弹窗归属终端，更容易确认授权状态。
